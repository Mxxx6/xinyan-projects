# 美术赛道抖音 / 视频号内容分析工具包

围绕美术培训赛道，抓取抖音 / 视频号爆款内容，做语音转文字 + OCR，用「五因子爆款归因模型」分析，并自动生成选题报告 PDF。

## 组件

- **爬虫**：抖音用户主页视频抓取、视频号内容抓取、本地视频语音转文字 + OCR
- **分析引擎**：FastAPI 服务 + 五因子归因模型 + OCR 分析
- **脚本**：各细分赛道（口播 / 整活 / 形转色变 / 美院附中 / 500 条报告 / 素描选题库等）PDF 报告生成

## 目录结构

```
douyin-analysis/
├── 爬虫/            douyin_scraper / shipinhao_scraper / video_content_extractor
├── 应用/            FastAPI 服务（API + 分析引擎 + OCR）
└── 脚本/            选题库与 PDF 报告生成脚本
```

## 隐私

抓取原始数据、已生成 PDF 报告、JSON 数据等均未纳入仓库（见根目录 `.gitignore`）。
